Пилюля с пунктирной рамкой, как отрывной билет: по нажатию копирует текст. Два применения: промпт для ИИ-агента на первом экране и ссылка-приглашение другу.

Передаёт потребитель: `label` (что сделать), `hint` (короткая видимая часть), `value` (что копируется), `doneLabel`. С `menu` (`[{label, href}]`) рядом появляется круглая кнопка ⌄, она открывает список «Открыть в ChatGPT / Claude» — ссылки с уже вставленным промптом (`?q=`). `menuTitle` — подпись над списком.

- После копирования рамка становится сплошной `dusk`, кружок — галочкой.
- Ширина до 440px, с меню до 500px. Если буфер обмена недоступен, ничего не происходит: `hint` всегда видна текстом.
