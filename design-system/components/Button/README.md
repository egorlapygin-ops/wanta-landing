Кнопка-пилюля высотой 52px: подпись обычным регистром и круглая ячейка справа — повтор пилюли логотипа «текст | кружок».

- `primary` — заливка `dusk`, справа кружок `paper` с точкой `coral` (сохранённое место); при наведении точка подрастает. Одна на экран: «Скачать Wanta».
- `secondary` — `paper` с рамкой `line`; с `external` справа кружок `surface` со стрелкой ↗. Для второстепенного: «Для заведений».
- При нажатии кнопка чуть сжимается (scale .97).
- `href` делает ссылку, иначе `<button>`. Подписи — глагол и объект: «Скачать Wanta», не «Начать».
