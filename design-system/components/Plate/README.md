Генеративная дуотон-иллюстрация со скруглением `radius-l`: город сверху и круглые пины `coral` на месте сохранённых мест.

- Цвета только из `dusk-shadow` → `dusk-print` → `dusk-glow` и `coral`. Растр — упорядоченный дизеринг 4×4 с клеткой 2px; пины — круги, растрированные той же сеткой.
- `seed` фиксирует картинку: одна страница — один seed.
- `patches` — число мест (по умолчанию 9). `focus` обводит первое место тонким кольцом.
- `caption` — подпись `label` с точкой `coral`: количество мест, координаты, район. Координаты реальные.
- Ширина до `plate-max` (880px): Plate шире текстовой колонки и выходит вправо.
