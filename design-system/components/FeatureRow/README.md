Строка раздела «Что мы делаем»: иллюстрация слева, заголовок и абзац справа.

Передаёт потребитель: `illustration` (путь к SVG) или `glyph`, `title`, абзац (`children`). Иллюстрация декоративная: смысл передаёт соседний текст. Без `illustration` используется Glyph. Строки кладите в `.wn-features` (шаг `space-12`). Заголовок — `title` (Unbounded 18px), короткая фраза без точки: «Один тап до действия».
