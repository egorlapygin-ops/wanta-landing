Логотип Wanta: слово WANTA шрифтом SK Pupok Solid, 12px, трекинг 9px (Figma, узел 122:11902).

- `pill` — пилюля из приложения: фон `pill-glass`, разделитель `pill-divider`, аватар 24px с `shadow-avatar`. На сайте — только в шапке личного кабинета, где есть пользователь.
- `scale` — множитель кегля; трекинг всегда 0.75em. В SideNav — `scale: 1.5`.
- `avatar` — URL фото. Без него рисуется диск `blush`.
- Только латиница: в шрифте нет кириллицы. Для печати и соцсетей берите SVG из группы Logos.
- Не красьте в `dusk` и `coral`: слово всегда `ink`.
