# Wanta — сайт

Сайт Wanta на дизайн-системе Wanta Web. Сборки нет: Vercel отдаёт страницы как есть (`vercel.json`, `framework: null`). Одна Node.js-функция создаёт ссылки на корзину ВкусВилла.

| Путь | Что это |
|---|---|
| `index.html` | Главная: миссия, интент-слой для ИИ-агентов, Telegram-бот, схема «Рисунок 1» |
| `index.md`, `llms.txt`, `llms-full.txt` | Версия для агентов: главная в Markdown, выжимка о Wanta и полный текст сайта |
| `lab/` | Временно скрытая лаборатория: материалы сохранены для дальнейшей работы, публичные адреса перенаправляются на главную |
| `assets/` | Общие компоненты (`bundle.js`, React 18 с cdnjs), мобильное меню (`site.js`), стили (`bundle.css`), шрифт логотипа |
| `scripts/generate-agent-pages.mjs` | Обновляет `lab/index.md` и `llms-full.txt` из текущих текстов сайта |
| `api/vkusvill-cart.mjs`, `lib/vkusvill-cart.mjs` | Создание корзины через официальный публичный MCP ВкусВилла |
| `design-system/` | Исходники дизайн-системы: токены, брендбук, компоненты с превью, логотипы |

Локально (Node.js 22+; без установки зависимостей):

```bash
node scripts/serve.mjs 8765
```

и открыть http://localhost:8765/.

Кнопка «Заказать» отправляет выбранные количества в `/api/vkusvill-cart`. Сервер использует только три разрешённых товара, вызывает `vkusvill_cart_link_create` на `https://mcp.vkusvill.ru/mcp` и возвращает проверенную ссылку. ВкусВилл показывает состав и предлагает добавить его в корзину. Адрес, наличие, итоговая цена и оформление остаются на стороне ВкусВилла. Ключи, вход в аккаунт и токен Telegram-бота для создания ссылки не нужны.

Каталог проверен 28.10.2026: паппарделле с яйцом — `122166` (215 ₽), томаты черри «Виноградные» 400 г — `108505` (520 ₽), итальянские травы 12 г — `104870` (74 ₽). При замене товара сначала найти его актуальный ID через `vkusvill_products_search`, затем обновить соответствующие данные в `lib/vkusvill-cart.mjs` и `assets/recipe-illustration.js`. Количество — целое 0–40 на позицию; нулевые позиции не передаются. Цены в примере справочные.

Проверка серверной интеграции без внешних запросов:

```bash
node --test tests/vkusvill-cart.test.mjs
```

Живая проверка выполнена 28.10.2026: созданы ссылки через публичный MCP, в браузере проверены товары в окне «С вами поделились товарами». Через кнопку на локальном сайте переданы 2 упаковки пасты, 1 упаковка томатов и 0 трав — ВкусВилл показал ровно этот состав. Также проверены блокировка повторного нажатия во время запроса, восстановление после ошибки, пустая корзина и экран шириной 320 px. Заказ не оформлялся. Обычный `python3 -m http.server` подходит только для вёрстки: серверную кнопку он не обслуживает.

Публикация настроена через GitHub → Vercel: push в `main` обновляет [основной сайт](https://wanta-landing-inky.vercel.app/), отдельные ветки создают Preview. После выкладки проверить страницу и `/api/vkusvill-cart` уже на Vercel, а также перенаправления скрытой лаборатории.

Под демонстрацией расположен блок «Попробуй сам». Публичный [рилс с пастой](https://www.instagram.com/reel/DYkirOriMqI/) взят из успешных интеграционных проверок `wanta-recipes/docs/VALIDATION.md`; доступность исходной страницы повторно проверена 28.10.2026. Ссылка копируется в буфер обмена, при отказе браузера появляется выделенное поле для ручного копирования. Кнопка Telegram передаёт URL как черновик через `?text=…`; пользователь отправляет его в чат сам, при первом запуске сначала нажимает «Старт». Новый запуск обработки в Telegram при проверке лендинга не выполнялся. Основная ссылка задаётся в `DEMO_REEL_URL` в `index.html`; при замене обновить также `index.md` и сгенерированные страницы для агентов.

После правок в `index.md`, `lab/data.js` или `lab/markdown.js` обновить статические версии для агентов (нужен Node.js):

```bash
node scripts/generate-agent-pages.mjs
node scripts/generate-agent-pages.mjs --check
```

Сгенерированные файлы хранятся в Git вместе с исходными данными. Команда `--check` завершится с ошибкой, если экспорт отсутствует или устарел. Пока лаборатория скрыта, `llms-full.txt` содержит только главную. Для возвращения лаборатории нужно восстановить навигацию, включить её в полный текст и убрать перенаправления `/lab` из `vercel.json`.
